## Suffixes

*[p. 355]* ^pg355

### The suffix system

Suffixes are meaningful groups of sounds that we add to something else. Sanskrit uses many different suffixes, and these suffixes can cause many different sound changes. So it is important to understand what suffixes mean and what sound changes they cause.

We have already seen several kinds of suffixes. We have seen nominal endings:

nara + sya —> narasya of the man

verb endings:

gaccha + ti — gacchati

(someone) goes

and various other suffixes that we use with verbs:

nī + i > nāyi — nāyayati lead — make lead — makes lead

But in this topic, we'll focus on all of the other suffixes that Sanskrit has. We can sort these suffixes into two big groups. First are root suffixes, which we add to a verb root:

H4 +3 HA

man + tra — mantra think + (means) — “means of thinking,” mantra, counsel

nī + tra —> netra lead + (means) — “means of leading,” an eye

Next are nominal suffixes, which we usually add to a nominal stem: नर + स्य -> नरस्य

च्छ ~ च्छति a

नी + इ -> नायि -> नाययति

नी+त्र->नेत्र

*[p. 356]* ^pg356

mantra + in —> mantrin mantra + (characterized by) — minister, counselor

amara + tva —> amaratva immortal + (state of being) —> immortality

kuru + a — kaurava Kuru + (descendant of) — “descendant of Kuru,” a Kaurava (one of the main factions described in the Mahabharata)

What sound changes do suffixes cause?

As you can see in the examples above, suffixes can cause many different changes to the roots and stems they attach to.

The most common change is to strengthen the last vowel by making it a compound vowel. We saw an example of this with netra above:

nī + tra —> netra lead + (means) — “means of leading,” an eye

But suffixes can also cause other kinds of sound changes. For example, some suffixes don't cause a vowel change at all:

nī + ta —> nīta

lead + (past suffix) —> (has been) led

And others cause the letters c and j to shift to k and g:

śuc + a > śoka

grieve + (state) — grief, sorrow

HA + इन् -> मन्तिन्

अमर + त्व -> अमरत्व

कुरु + अ — कोरव

नी+त्र->नेत्र

नी + त -> नीत

रुच् + अ -> शोक

*[p. 357]* ^pg357

tyaj + a —> tyāga

abandon + (state) — abandoning, relinquishment

it

When we add a suffix to a root, sometimes we add an extra i sound between the root and the suffix:

nī + ta —> nīta lead —> led

qa + 3 +a o afad

vand + i + ta —> vandita venerate — venerated

Traditionally, this i sound is called it. Some roots use it, some roots don't use it, and some roots use it optionally.

### -tvā and -ya

Also known as: the gerund, the absolutive, the indeclinable or adverbial participle

We will start this topic by learning about the root suffixes -tvā and -ya. Both of these suffixes create uninflected words.

-tv Also known as: ktvā

When added to some root that means “X,” -tvā creates a word that means “after X-ing.” In other words, -tvā shows that one action happens before another.

For example, suppose we have these two simple sentences:

rāmo laṁkām gacchati.

Rama goes to Lanka.

rāmo rāvaṇnam paśyati.

Rama sees Ravana.

We can combine them like so:

rāmo laṁkām gatvā rāvaṇam paśyati Rama, after going to Lanka, sees Ravana.

-tvā can cause many sandhi changes. We will discuss these sandhi changes further below.

-ya Also known as: lyap

-ya has the same meaning as -tvā. If the root uses a verb prefix, we always use - ya. Otherwise, we use -tvā.

For example, if we have these two simple sentences:

रामो Sgi गच्छति।

रामो रावणं परयति।

रामो ggi गत्वा रावणं परयति

*[p. 359]* ^pg359

hanumān rāmam pratigacchati.

Hanuman returns to Rama.

hanumān hrsyati.

Hanuman rejoices.

Then we can combine them with -ya:

hanumān rāmam pratigamya hrṣyati.

Hanuman, after returning to Rama, rejoices.

### -ta and -tavat

In this lesson, we will learn about two more common suffixes. Both of these suffixes create adjectives.

-ta Also known as: the past passive participle, the PPE kta

The suffix -ta is important and powerful. When we add it to a root that means “X,” we usually create words that mean “(has) been X-ed.”

Here are some examples of -ta. Note that it causes the same sound changes as - tvā:

nī —> nīta lead —> led

kr — krta

do, make — done, made

-ta usually creates words that express karmani prayoga. In English, we would say that these words have a passive sense:

~

rāmena śarah krtah.

By Rama, an arrow has been made.

But if the root implies a sense of motion, it has the normal kartari prayoga sense:

gam —> gata go —> (has) gone

And likewise for other roots, especially if they don't have an object:

नी -> नीत

The suffix -tavat has a similar meaning to -ta. When we add it to a root that means “X,” we usually create words that mean “has X-ed.” Here are some ex-

### -tum

-tum

Also known as: the infinitive, tumun

In this lesson, we will learn about the root suffix -tum, which creates uninflected words.

When added to some root that means “X,” -tum creates a word that means “to X.” Here are some examples:

aham khāditum icchāmi.

I want to eat.

etān na hantum icchāmi.

I don't want to kill them.

(Bhagavad Gita 1.34)

We almost always use -tum with another verb. Often, we use -tum words to express that someone wants to do something:

gajah khāditum icchati.

The elephant wants to eat.

But there are many other verbs that we can use with -tum:

gajah khāditum śaknoti.

The elephant is able to eat.

gajah khāditum jānāti.

The elephant knows (how) to eat.

gajah khāditum ārabhate.

The elephant begins to eat.

अहं खादितुम् इच्छामि।

गजः खादितुं जानाति।

गजः खादितुम् आरभते।

*[p. 366]* ^pg366

gajah khāditum yatate.

gajah khāditum arhati.

And in a more general way, -tum can show the reason that some action was done:

gajah khāditum carati.

gajah khāditum dhāvati.

### -tavya, -anīya, and -ya

Also known as: the gerundive, the future passive participle, the potential participle, krtyāh

The suffixes tavya, antya, and ya all create adjectives, and they all have the same meaning. When added to a root that means “X,” they all mean “should or must be X-ed” or “able to be X-ed.”

Here are some examples:

tvayā vanam gantavyam.

By you, the forest must be gone to. (literal translation)

You must go to the forest. (natural translation)

~

mrgo na hantavyah.

The deer must not be killed.

bhāve prayoga

These suffixes often express bhāve prayoga. When they do, they use the neuter case 1 singular:

~

yoddhavyam

There should or must be fighting.

Here is an example from the Bhagavad Gita:

kair mayā saha yoddhavyam With whom and me must there be fighting? (literal translation) With whom must I fight? (natural translation)

-vat (feminine: -vatT) has the same meaning as -mat. We use -vat if the stem ends in m or a, or if it has m or a as its next-to-last letter:

bhaga + vat —> bhagavat (a is the last letter)

laksmī + vat — lakṣmīvat (m is the next-to-last letter)
