# CCEL footnote runs (C-01b)

Scripts of 28 Oct 2026 for the audit finding C-01(b): in the two CCEL books (Augustine NPNF1 6, Chrysostom on Matthew), the converter put the footnotes of some PDF pages at the end of the page block before, so the footnote text sat one page early (often after the 1888 print-page number that opens them). Run in the workspace, on a dump of the notes (a runner job that writes every note of the two books to JSON) and the pdf.js text of the pages (a job like pf442).

| file | what it does |
|---|---|
| `detect.py` | lists page blocks whose footnote zone holds numbers whose calls are in the next block (`cands.json`). 28 Oct: 269 blocks. |
| `plan2.py` | for each, the start of the run: the first such number, extended back over the pieces (a print-page number, Greek text that precedes its number) that the next PDF page has and this one lacks; the run ends at the block's end. |
| `strict.py` | keeps a cut only where it falls on a clean item boundary, checked against both PDF pages (`ok.json`, `hold.json`). 28 Oct: 204 kept, 65 held. |
| `build_spec.py` | moves each kept run to the next page block (before its own footnotes, or at its end) and writes whole-block edits for `edits-job2`; it checks that the non-space characters and the `^pg` blocks are unchanged. |
| `reader-brief.txt` | the readers' brief for the held cases: the block's footnote text and the two page images; the reader gives the words where the next page's footnotes begin ("move"), or "mixed", "none", "unclear". |
| `apply_read.py` | applies the readers' cut points where the quote occurs once, the words after it are on the next page and the text before it on this one; the same whole-block edits and checks as `build_spec.py`. |
| `lost-number-scan.js` | (pf472) lists the calls `<sup>N</sup>` whose number N appears nowhere else in the note. |
| `s_star.py` | (28 Oct, fourth session) moves a footnote number the converter put after its own note's text to before it, where the PDF text settles it (the note's text occurs once in the page block, followed by the number, and not preceded by it); accent-blind, then also Greek-blind. |
| `lost_plan.py` | for each lost call: the PDF page whose footnote run lists it and the note's text from the pdf.js text; in the page block, A/A1 (text there, number lost: "N " before it) or B/B1 (whole note lost: "N text" after the previous note, or as the page's only note); anything else held with a reason. |
| `nt_link.py` | links New Testament references in restored notes as the two books' existing footnotes are linked (the abbreviation map is read from those links; 4,234 of 4,253 existing link groups reproduced); Old Testament references stay plain, as everywhere in these books. |
| `build_edits.py` | turns the plan into whole-page-block edits and checks them (characters, `<sup>` calls, `^pg` lines, every lost number present). |
| `combine.py` | the original notes through `s_star.py` and the plan to one `edits-job2` spec of whole page blocks; moves a number that ends the previous paragraph to the start of its own note; checks; counts the page blocks whose footnotes match the PDF's list, before and after. |
| `footnote-check-brief.txt` | the checkers' brief: a page image and the note's text for that page; every printed footnote with its own number directly before its own text. |
| `diff_blocks.py` | (28 Oct, fifth session) lists the page blocks whose footnotes still differ from the PDF's list, with a first sorting (`lost`, `number-misplaced`, `greek`, `text-differs`). |
| `s_move.py` | moves a footnote number that stands bare elsewhere in its page's footnote zone (often inside the previous note's text, as 3966 before οὐκ) to just before its own note's text, only where the move is unique, at a word boundary and outside links; body calls are never touched. |
| `compose.py` | the vault's notes through `s_move.py` and `lost_plan.py` (dropping any plan entry whose number already stands in the zone) to one `edits-job2` spec of whole page blocks, with the usual checks and the match count before and after. Run with `PYTHONPATH` set to this folder (for `nt_link`). |
