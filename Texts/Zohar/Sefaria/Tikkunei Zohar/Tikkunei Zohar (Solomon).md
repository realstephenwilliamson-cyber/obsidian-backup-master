# Tikkunei Zohar (Solomon)

Tikkunei ha-Zohar in David Solomon's translation (2024) with the Constantinople 1740 text it is aligned to, one note per folio side as in Sefaria's structure, with the Tikkunim headings. Solomon's translation (and the aligned Constantinople 1740 text) covers folios 17a–63a; the work runs to folio 148a in Sefaria's structure. The rest is not built.
