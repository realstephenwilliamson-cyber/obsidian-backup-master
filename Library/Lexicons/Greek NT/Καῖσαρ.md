# Καῖσαρ

[[Greek NT Lexicon (MorphGNT)]] · noun

**Dodson:** Caesar — Caesar, a surname of the gens Iulia, which became practically synonymous with the Emperor for the time being; in the Gospels it always refers to Tiberias. (Strong's 2541; headword Καῖσαρ, αρος, ὁ)
