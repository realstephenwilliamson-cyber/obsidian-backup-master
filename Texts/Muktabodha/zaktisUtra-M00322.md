# śaktisūtra

**Catalog number:** M00322  
**Manuscript:** Manuscript No. : 1-619 Reel No. : 628/9  
**Published:** Muktabodha Indological Research Institute, India

## Description

Description by Mark S.G. Dyczkowski:
This work belongs to the Kubjikā school, the paścimāmnāya. It contains details of basic ritual procedures of this school. This work was probbly not written in Nepal where she is nowadays almost exclusiveely worshipped. The following reference in a colophon to Konkana, that is, the region around modern Goa suggests that it may have been composed there.
iti sūtrasaṃgrahe śrīkauṃkaṇādhikāre
This not at all impossible as we know that much of the early history of this school is associated with that part of India.
