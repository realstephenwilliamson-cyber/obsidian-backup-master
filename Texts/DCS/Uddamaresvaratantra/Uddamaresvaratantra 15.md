# Uḍḍāmareśvaratantra — Chapter 15

[[Uddamaresvaratantra 14|← Chapter 14]] · [[Uddamaresvaratantra|← index]]

ṣaṭkoṇaṃ yantraṃ likhitvā tatra ṣaṭkoṇe oṃ kurukulle svāhā iti mantraṃ pūrvakoṇe likhet

^s1

kuru ity akṣaradvayam aparakoṇe likhet

^s2

akṣaraikaṃ pūrvāvartakrameṇa lekhitavyam

^s3

tato bhūrjapattre imaṃ mantraṃ likhitvā gṛhadvāre dehalyā ekadeśe dhṛte sati gṛhasarpam uccāṭayati vivaradvāri dhṛte vivarastho naśyaty eva

^s4

raktakaravīrapuṣpam āmrapattrabhasmanā liptaṃ tatkṣaṇād eva śubhraṃ bhavati tathā gandhakadhūpenāpi bhāvitena śuktir bhavati

^s5

loke hayamāra ityākhyasya raktakaravīrasya puṣpaṃ tūlavartikāgandhakena saha saṃyojya tatkṣaṇād eva jvalati

^s6

tathā ṭaṅkanaharidrābhyāṃ kṛte lepe kuṅkumakāntir bhavati

^s7

purāṇaśuṣkagomayaṃ yadā jale pātayet tadā bhīmoṣmaṇā tasmād budbudam utpadyate

^s8

evaṃ gauraṃ tu bhūmyupari bhūtalaṃ spṛṣṭvā raktakaravīravṛkṣo jāyate iti

^s9

rūpake tāmre bhramara iva kumbhe samarpayet kiṃcid anuyogitvena mano'nurāgo bhavati tāmbūlarāgataḥ naśyati haridrārāgo ravikiraṇāt

^s10

oṃ huṃ sati kurur upakṣiśabdataḥ kuralakuṅkumena iti prasiddhiḥ kroñca ity api tasya nāma jihvākrīṃkṛtaṃ vāmakaratalamadhyalagnaparilepaṃ darśayitvā uditaviśvadhārābhasmanā punar api karatalalagnāt pradarśya gatyāścaryamate śiśudugdhabhāvitāt śodhayitvā gavādidugdhaṃ coṣṇaṃ kāṃsyapātre kṛtvā tīkṣṇataraṃ dhṛtvā taṇḍulanikṣepaṇena kṣīraṃ bhavati

^s11

bhūrjapattrapuṭakaṃ tilatailena dīpayitvā vividhabhakṣyānnaṃ sādhayet yathā lauhabhājane sādhyate

^s12

vārtākarañjikāpalam iti tat sūtreṇa veṣṭayitvā dīpayitvā ca jvālayet tenāvisūtreṇa veṣṭite ca sūtraṃ saṃdahyate vārtākaś ca pacyate

^s13

ādipaṅktau sapta svarān saṃlikhya tadadhaḥpaṅktau kādisaptavargāt saṃlikhya tadadhaḥpaṅktau haridrādikrameṇālekhanīyā tatra svaravarṇayojanena saṃkocanād akṣarakoṣṭhādisaṃsparśanāt saṃjāyate

^s14

bahuṣu madhyeṣu dattasaṃjñākṛtasaṃketaś cauraḥ svadṛṣṭim api saptasaptasvarādau jānāti

^s15

vyāpāramadhye kṣaṇarasikaś cauro jñāyate kṛto bhadradravye

^s16

kutrāpi dhattūrakabījaṃ kṣiptvā tad vā bhakṣati tadā tadguṇādiphalaṃ labhyate asau cauraḥ iti

^s17

svalpacaracaurās tu vastulābhe pradātāraḥ

^s18

kṣīryarkādivṛkṣadugdhena saṃlikhitaṃ cauranāmākṣaraṃ karatale 'pi likhitam anantaraṃ bhūrjapattre kṛtam api mardane sparśayitvā bhakṣituṃ tato dadāti aparilikhitaṃ cauranāma pattrayuktaṃ ca arigṛhagarbhamṛttikākāṇḍakaṃ bhavati

^s19

jale sādhunāma pattrayuktamṛttikā ca jale majjati tataḥ spṛṣṭvā kriyate asau cauraḥ iti

^s20

kṣīritarudugdhalikhitakṣudralekhe aṅgāracūrṇena marditāḥ spaṣṭā bhavanti

^s21

kūṭo 'pi viparītalikhitavarṇa ādarśādau pratikṛtibhāvāpanno varṇavaiparītyāt prativivardhitanyāsaḥ atidṛḍhā masī bhavati

^s22

nimbatālake samatāmrabhājane yāmamātramarditena vidhir astu samabhāgatā yathā āmalakīharītakīvibhītakanimbakhādirāṇām nīrākhyārājakaravīrarasaiḥ samastarasakajjalamuktamardanaprakāreṇa yāmamātreṇa pratyekaṃ yena prakāreṇa masidravyaṃ jāyate

^s23

śirīṣavṛkṣatvakcūrṇaṃ khadiraṃ vinā tāmbūlarāgaṃ janayati

^s24

tiryaka bhūmau nārikelaphalam asthisahitaṃ mukhena karṇikāyām ekena prahāreṇa dvidhā bhavati

^s25

laghukāṣṭhasūkṣmaracitapākāṃ vinā pādaikaṃ vā bhramati

^s26

guñjāphalāsthiliptaṃ stambhitaṃ taduttarapādaṃ prayojya prapadātyantaṃ bhramati tadā pādatale tālakāralagnā uttiṣṭhati

^s27

evaṃ laghukāṣṭhanirmitāsamakaḥ pāpapurahāsārthaṃ dattamukhaveṣṭaṃ kiṃcit yas tena sitavastrādau kaṭyāṃ lagnam upatiṣṭhamānās tiṣṭhati

^s28

evaṃ niviḍāmbarapihitajambādau adhomukhakāṃsyabhājananihitam aṅgāraṃ na dahati vastraṃ dahati cāpi śiśirajalamiśritam api ānataphalacūrṇabhāvitakalaśaḥ tīkṣṇaś ca kāṃsyabhājananihitaṃ guruḍḍanāpy aśaktaṃ na bhavati tadānīṃ tiktaṃ yāti yacchuktaṃ miṣṭam eti kajjalacavikācūrṇābhyāṃ kramasaṃlikhitapustakamadhyakāraṇe 'pi yatheṣṭayā pacyate yathā kaṭāhe ramyatare madhunāgniprajvalite sakuṇḍādau jalapūrṇe adhomukhe ujjvalaṃ svayam eti dhūmābhyāṃ svayam udgirati vartidvaye śaśaviṣṭhāpūrṇagarbhe kamaṭhair adhovartiviṣṭhāyitāpi upari jvalajjvālājvalitavartijvālām api jvalitadhūmam aṅgāratīkṣṇaśikhayā nāḍikādau

^s29

vālivāte 'yaṃ prayogaḥ kāryaḥ

^s30

vāmakarāṅguliparyantaṃ gopitaṃ sūtracihnam apy acihnaṃ ca dṛśyate janasya viṣamasamākṣareṇa vīkṣite kālaḥ asamam api puruṣaṃ jānīyāt

^s31

pañcadāḍime śikhare masiguṇite yaddhi bhavati tāvat guṭike vijānīyāt

^s32

akālavakre sati kālam atha phalacūrṇena militvā bhasmanā saha ghṛtena kākañjikā sahasā bhavati

^s33

agādhasthirajale dhūmacūrṇena likhitacintādi bhītavad bhāṣate na nimajjatīti

^s34

samadaśaghṛtajadhṛtasamāveśārdhaṃ dhṛtamūṣalaṃ tiṣṭhati

^s35

puṣyanakṣatre kuṅkumāvartitena bāṇena dūrastham api lakṣyaṃ bālo 'pi vidhyate

^s36

ṣaṇḍaṃ gomayānāṃ vartidīpakāntyā dagdhaṃ madhye hataśaśarudhiraṃ dṛśyate tatrāpi tailaṃ yat kiṃcid iti

^s37

śvetārkaphale tūlakaṃ sarṣapasamaṃ tailenaikīkṛtavartikadīpajvālāyāṃ gṛhoparivaṃśādidāru sarvaṃ sarpa iva dṛśyate

^s38

bhujagataile sachidrabhāṇḍe bhujaṃgaṃ kṣiptvā acchidrabhāṇḍāntare vyavasthitam agnipātena jalaṃ jvalati

^s39

tadaiva tailaṃ pūrvaprakāreṇa kṛṣṇāṣṭamyāṃ maṇḍūkatailāṅkitena sarvaṃ śātrava sarvaṃ bhavati

^s40

dīpakāntyā dīpayitvā yat kiṃcic ca kukkuṭapakṣicañcvādividagdhanālalakṣitā satī hṛtā lekhā yadāyāti harikapālaṃ dhṛtvā bhavati tadā taj jalapūrṇāṃ ca kalaśaṃ riktakaṃ bhavati tathā maricaśuṇṭhī pippalīcūrṇenobhābhyāṃ vāmacaraṇatalaṃ liptvā tenāhato vṛkṣaḥ kalpavṛkṣaś ca nameruphalaṃ prasūyate

^s41

kṛṣṇā gauḥ prasavakāle tadvat samānavarṇaṃ jarāyur āgatatvena prajāreṇḍalā phalaṃ dṛṣṭvā muṣṭigṛhīte uccais tamasi phalaṃ prāyeṇa kṛtvā pradāsyati tathā kālāyitamudrikā varagostanī syād āpatitā gṛhītā nikṣiptā tu aṣṭau pūrvaphalāni janayati

^s42

samustāharitālamanaḥśilābhyāṃ navanītādiyogena kāritāñjane mayūrasya viṣṭhayā kṛtvā hastaṃ limpet tatra sthitaṃ dravyaṃ brahmāpi na paśyati

^s43

samukhaṃ phalacūrṇaṃ miśrodvartanakājale kṣiptvā krimisahasratulyaṃ dṛśyate

^s44

hayakālīyakasya śoṣitasya cūrṇaṃ gavaśīrṣakeṇa samudvartanena tātkālikaṃ sūkṣmajale niḥkṣipya sabījaṃ kṛṣir uccalati

^s45

adhaḥpaṭenāśasyāvaśyādi dṛṣṭvā pādāgrasthitaṃ dravyaṃ dṛśyate

^s46

japākusumodvartitāṅgaṃ churikādau kaṇācitaikakīṭakāphalākhyā yantrite rudhiravaj jaḍitaṃ kṣīrivṛkṣatvagavabhāvitā tailāktā vastravartir jalair jvalati

^s47

evaṃ samudratailayuktāpi vartikā jvalati

^s48

droṇakapuṣpādīni kṣudrapuṣpāṇi cūrṇāgre viniṣkṣipya dhattūrabījāni jalasiktāni sajīvavat phalanti

^s49

ikṣuḥ kukkuṭībījacūrṇena sudarśanapattram iva tatkṣaṇāt jāyate

^s50

masṛṇakarpaṭaṃ nirmalakāṃsyabhājane 'rkasammukhaṃ sthāpanena vartulakayogād agnir uttarati

^s51
