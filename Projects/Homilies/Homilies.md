# Homilies

One note per homily, named `YYYY-MM-DD Occasion` (for example `2026-11-29 Advent 1B`). The quickest way to start one is the **Start a homily** button on [[Home]], which picks the coming Sunday's readings from the study plan. A new note made in this folder any other way asks you which Sunday or feast it's for.

Each note pulls in the full text of that Sunday's readings, lists any earlier homily you wrote on the same readings (three years back), and has space for notes and a draft. Move a homily along by changing its `stage` property: `idea` → `drafting` → `finished` → `preached`, and put where it was preached in `preached_at`.
