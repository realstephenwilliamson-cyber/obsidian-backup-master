# Kitzur Shulchan Arukh (Davis)

The *Kitzur Shulchan Arukh* in Rabbi Avrohom Davis's translation (Metsudah, 1996), one note per chapter (220 notes), each se'if a block (`^72-4` is chapter 72, se'if 4); Davis's notes are the footnotes. Sefaria describes it as a "Popular handbook with simplified summaries of laws relevant to daily life, published in 1864." The author's name is not in Sefaria's export, so it is not given here. Chapter 32 has no English in this translation on Sefaria, so it has no note.
