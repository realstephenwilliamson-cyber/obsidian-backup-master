# Classes

One note per class, for the weekly adult formation class: your readings, points and questions. Start one from the **Class note** template (Templater: *Create new note from template*), named `YYYY-MM-DD Class Occasion` (for example `2026-11-15 Class Proper 28A`). It is written so it also works as slides (the core Slides plugin splits at each `---` line) or as a handout. The template is a draft; it does not fill itself in yet.

Move a class along with its `stage` property: `idea` → `drafting` → `finished` → `taught`.
