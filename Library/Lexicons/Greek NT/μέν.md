# μέν

[[Greek NT Lexicon (MorphGNT)]] · conjunction

**Dodson:** truly, indeed — an untranslatable particle, generally answered by "de", each of the two introducing a clause intended to be contrasted with the other. (Strong's 3303; headword μέν)
