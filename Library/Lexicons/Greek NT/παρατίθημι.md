# παρατίθημι

[[Greek NT Lexicon (MorphGNT)]] · verb

**Dodson:** I set before, serve, entrust to — (a) I set (especially a meal) before, serve, (b) act. and mid: I deposit with, entrust to, (c) I bring forward, quote as evidence. (Strong's 3908; headword παρατίθημι)
