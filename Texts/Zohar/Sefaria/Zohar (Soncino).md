# Zohar (Soncino)

The Zohar in the Soncino translation (1933), one note per folio side following the standard pagination (volume, folio, side) from the Daf structure in Sefaria's schema. Each passage carries a block ID made from its Sefaria reference (`[[Zohar 1.001a#^introduction-1-1]]`). Passages Soncino does not translate are noted in place; folio sides with no Soncino text have no note. The Aramaic is not included: the only Aramaic version requested (Vocalized Zohar, Israel 2013) has no stated license on Sefaria.
