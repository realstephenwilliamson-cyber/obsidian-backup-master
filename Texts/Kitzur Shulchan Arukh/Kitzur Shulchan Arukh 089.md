# Kitzur Shulchan Arukh 089

← [[Kitzur Shulchan Arukh 088]] · [[Kitzur Shulchan Arukh]] · [[Kitzur Shulchan Arukh 090]] →

*Chapter 89* · [[Kitzur Shulchan Arukh]]

**1.** If you intentionally placed a *muktzeh* object upon your vessel on Friday[^1] and you intended that it be there[^2] at the onset of Shabbos,[^3] the vessel is considered a base for a prohibited object [*muktzeh*]. Even if the *muktzeh* object was removed on Shabbos; nevertheless, since it lay there at twilight, and the vessel then became a base for a prohibited object, it is forbidden to be handled afterwards for the rest of the Shabbos day[^4] even if you need the object itself or the space it occupies.[^5] ^89-1

**2.** If at the onset of Shabbos, a permitted object was lying there too, making the vessel a base for both a prohibited object *and* a permitted object, if the permitted object is more important to you, you may handle it [i.e. the base vessel]. But, if the prohibited object is more important[^6] to you, you are forbidden to handle it. It is, therefore, best to place the *challos*[^7] on the table before twilight, so that the tablecloth and the table become a base for [both] the candles *and* the *challos*, and it will be permissible to handle them.[^8] If you did not do this, then the tablecloth and the table become a base solely for a prohibited object and it is forbidden to handle them. However, having done so, if there is an important need, such as if a [burning] candle fell on the table and it must be shaken off, you may rely on the *poskim* who rule that the rule of base does not apply unless you intended that the *muktzeh* object remain there for the entire Shabbos day,[^9] and since it is customary to have the candlesticks removed in the morning by a non-Jew, it does not become a base. ^89-2

**3.** If you had money in your pocket[^10] you may handle the garment, because the entire garment is not a base, only the pocket, and the pocket is subordinate to the garment.[^11] However, you may not wear it even in the house, lest you inadvertently go out into the public domain.[^12] However, if a table drawer contains money, it is forbidden to move the table, because the drawer is a vessel unto itself[^13] [^14] and not subordinate to the table. ^89-3

**4.** Nothing becomes a base unless the *muktzeh* object is lying there at twilight. However, if it was not there at twilight, but was put there afterward, it does not become a base and the vessel may be handled even while the *muktzeh* object is on it.[^15] You may, therefore, shake the table or tablecloth [to remove] bones and peels, provided the table and tablecloth have not become a base as a result of the candles, as was discussed above, paragraph 2. ^89-4

**5.** [The vessel] does not become a base unless you intentionally placed [the *muktzeh*] to remain there at twilight.[^16] But, if it was left there as a result of forgetfulness or if it fell there on its own, [the vessel] does not become a base.[^17] ^89-5

**6.** It does not become a base unless the vessel belongs to you. But, if you placed a *muktzeh* object on a vessel belonging to someone else, it does not become a base, because you cannot cause someone else's object [to become forbidden] without his consent.[^18] ^89-6

[^1]: According to some, this applies even where it is מְלַאכְתּוֹ לְאִיסוּד —i.e. *muktzeh* due to it being an object that is used for work prohibited on Shabbos. (This is the most lenient type of *muktzeh* since you may move it when you need it for a permitted use or for the space it occupies.) [*Tehillah LeDavid* 308: 1] *Yeshuos Yaakov* is inclined to permit בָּסִיס for מְלַאכתּוֹ לְאִיסוּר *Peri Megadim* (308) remains doubtful.
[^2]: Or if it is the usual place for the *muktzeh* to be kept. [*Mishnah Berurah* 309: 18] Accordingly, money that was left in a purse would render the purse a בָּסִיס. However, *Biur Halachah* (266: 12) cites Derech Chaim that the purse is not a בָּסִיס . A possible explanation might be that he is referring to a purse which is normally emptied before Shabbos. [See *Chazon Ish* 49: 10; also *Mishnah Berurah* 310: 25.]
[^3]: See paragraph 5. This applies only if you intended it to remain there the entire twilight period. [Rabbi Akiva Eiger 310; *Peri Megadim* 279; *Shulchan Aruch Harav* 310: 7; *Mishnah Berurah* 309: 19]
[^4]: Something that was *muktzeh* at twilight remains *muktzeh* the rest of Shabbos, even if the cause of the *muktzeh* was removed.
[^5]: A בָּסִיס attains the same degree of *muktzeh* as the *muktzeh* object which created the בָּסִיס.
[^6]: Or equally important. [*Mishnah Berurah* 310: 33]
[^7]: Or silverware and dishes (*Peri Megadim* 279) since they are more important than the flames of the candles. However, *Aruch Hashulchan* (279: 1) requires that the permitted items be more important than even the candlesticks.
[^8]: For the purpose of using the table or the space occupied by the table and provided you cannot first easily shake the *muktzeh* off the table. [See *Mishnah Berurah* 310: 34; 277: 18] According to most opinions the table may be moved even if the *challah* is no longer there. [*Shulchan Aruch Harav* 277: 6; *Mishnah Berurah* 377: 18] Some, however, permit this only where a loss may be involved. [*Minchas Shabbos*]
[^9]: See *Shulchan Aruch* 309: 4 and *Biur Halachah*.
[^10]: See Chapter 88: 13.
[^11]: It is preferable to first shake the money out. [*Mishnah Berurah* 310: 29. Also see ibid 310: 30.]
[^12]: *Rema* 310: 7.
[^13]: This is true only if the drawer can be completely removed from the table. Otherwise the drawer is considered only as a subordinate part of the table. [*Mishnah Berurah* 310: 31]
[^14]: Provided the drawer is used exclusively for *muktzeh* items. If the drawer normally holds other objects, then only the drawer is a base for that Shabbos and the table may be moved. [*Mishnah Berurah* 310: 31]
[^15]: *Magein Avraham* 308: 50. However, *Taz* and *Yeshuos Yaakov* rule that while the *muktzeh* is on the vessel it is a base until removed. It is, therefore, preferable to shake off the *muktzeh* if practical.
[^16]: See paragraph 2.
[^17]: If you placed it there without thought, *Mishnah Berurah* (309: 18) cites conflicting opinions.
[^18]: If your placing the *muktzeh* there is of benefit to the other person, the vessel becomes a base. [*Magein Avraham* 309: 8, see also *Minchas Shabbos* 89: 22.]
